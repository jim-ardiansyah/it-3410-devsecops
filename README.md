# IT 3410: Cloud DevSecOps

Welcome to **IT 3410: Cloud DevSecOps!**

This course introduces you to **DevSecOps on AWS**, combining DevOps practices with security throughout the software development lifecycle. You will learn how to build, deploy, monitor, and secure applications using AWS services and automation.

## What You'll Learn

Throughout the course, you will gain hands-on experience with key DevSecOps concepts and tools, including:

- **CI/CD** — Build automated pipelines using AWS CodePipeline, CodeBuild, and CodeDeploy.
- **Infrastructure as Code** — Use AWS CloudFormation to automate and manage infrastructure.
- **Security** — Apply AWS security services such as IAM, KMS, and GuardDuty.
- **Monitoring and Logging** — Use CloudWatch, CloudTrail, and AWS Config to monitor and audit your environment.
- **Security Integration** — Incorporate security testing and compliance checks into the development process.

## Course Goal

The goal is to help you understand how development, operations, and security work together to deliver secure and reliable applications faster and at scale.

## Outcomes

By the end of the course, you will have practical experience applying DevSecOps principles and AWS services to real-world scenarios. The course also provides a foundation for preparing for the **AWS Certified DevOps Engineer – Professional** certification.
